# Practica_POO
Desarrollar aplicación de consola para gestionar Biblioteca Universitaria con: altas/bajas/edición de materiales, gestión de préstamos y devoluciones, búsquedas/ordenaciones, sanciones por retraso y un módulo de estadísticas. Modelado OO, jerarquía polimórfica, modularidad, STL, y gestión manual de memoria con punteros.
